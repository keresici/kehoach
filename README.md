# Kế Hoạch – app cá nhân

Kế hoạch năm/tháng/ngày (bảng 3 cột: việc gì · trạng thái · lý do chưa xong), chi tiêu, thu nhập, nhật ký & bài học.

- Chạy hoàn toàn trên thiết bị, **dữ liệu không lưu trên GitHub** (chỉ nằm trong máy của bạn).
- iPhone: mở link GitHub Pages bằng Safari → Chia sẻ → Thêm vào MH chính.
- Sau lần mở đầu, app chạy offline vĩnh viễn từ bản đã lưu trong máy.
